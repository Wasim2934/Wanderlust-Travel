# 🌍 Wanderlust - Responsive Travel Landing Page

A modern and fully responsive travel landing page built using **HTML5** and **CSS3**. This project focuses on creating a clean user interface that adapts seamlessly across desktop, tablet, and mobile devices.

---

## Live Demo - https://wasim2934.github.io/Wanderlust-Travel/

---

## ✨ Features

* Responsive Navigation Bar
* Hero Section with Background Image
* Destination Cards Section
* Features Section
* Testimonials Section
* Responsive Footer
* Mobile, Tablet, and Desktop Support
* Hover Effects and Modern UI Design

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Media Queries

## 📚 What I Learned

Through this project, I gained hands-on experience with:

* Building responsive layouts using Flexbox and Grid
* Using Media Queries for different screen sizes
* Creating reusable UI components
* Structuring HTML using semantic elements
* Improving user experience across devices
* Writing cleaner and more organized CSS
